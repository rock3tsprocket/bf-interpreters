# Brainf\*\*k interpreter written in shell

## Why?????
I have no clue.

## What shells does this run on?
Basically any shell as long as it's POSIX.2 compliant.

## How fast is this?
On an Intel Core i5-4460 using BusyBox's ash, this interpreter takes ***21 minutes and 58 seconds*** to draw a [Sierpiński triangle](https://github.com/pablojorge/brainfuck/blob/master/programs/sierpinski.bf).
